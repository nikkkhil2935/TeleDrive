# Changelog

All notable changes to **Lumio Photos** will be documented in this file.

## [1.0.0] - 2026-11-21

### Added
- Complete Google Photos-inspired responsive interface with Light, Dark, and Midnight OLED themes.
- Direct browser MTProto WebSocket transport via client-side Telegram protocols.
- 7-step guided onboarding wizard with auto-fill credentials helper and QR code authentication.
- AES-256-GCM client-side vault encryption with PBKDF2 key derivation.
- Vertical fast date scrubber bar with year jumping.
- Duplicate finder and clean-up module with single-tap trash actions.
- Command palette (`Ctrl+K` / `Cmd+K`) for rapid navigation.
- Privacy dashboard with GPS stripping and zero-server data transparency diagrams.
- Resumable upload and download transfer engine with flood-wait cooldown handling.
